🔌 Add it to YOUR website (2 lines)

Copy pet-widget.js to your site, then paste this right before </body> — works on WordPress, plain HTML, anything:

<script>
  window.PetConfig = { name: "Mango", size: 110, controls: true };
</script>
<script src="pet-widget.js"></script>

For WordPress: paste the snippet into a Custom HTML block, or add it in your theme footer (Appearance → Theme File Editor → footer.php), or use any "insert headers & footers" plugin. Upload pet-widget.js to your media/files and point src at its URL.

⚙️ Options & API

Everything is optional — the defaults just work:

window.PetConfig = {
  name:     "Mango",   // pet's name
  size:     110,       // pet size in px
  controls: true,      // show the 🐾 panel
  bottom:   0,         // px above the bottom of the screen
  zIndex:   999999     // stacking order
};

Control the pet from your own code:

Pet.jump();  Pet.fly();  Pet.dance();  Pet.feed();  Pet.sleep();
Pet.say("Welcome to my site!");
Pet.setName("Pip");
Pet.command("dance");   // same commands as the text box
Pet.stats();             // { food, fun, energy, name }

🎮 What the pet does

  • Lives on its own — wanders, hops, jumps, flies around the whole screen, dances, and naps when tired.
  • Tap to pet — hearts, wiggles, and happy chatter.
  • Stats — 🍎 food, 💖 fun, ⚡ energy slowly change over time and are saved between visits.
  • Commands — type jump, fly, dance, sleep, feed, come, name Pip…
  • Mobile friendly — touch controls, safe-area aware, and it never blocks your page content.
